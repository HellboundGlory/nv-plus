THIRD-PARTY NOTICES — NV+ launcher (Launcher.exe)

This file indexes the license texts of the 314 external packages in nv-plus/launcher/Cargo.lock, which Launcher.exe is built from for Windows (the build-time crates included). Package names, versions and license expressions come from each package's Cargo.toml in the local Cargo registry; the files were copied from that exact version there. A package that ships no license file gets the standard text of its license expression (MIT with its authors as the copyright line, Apache-2.0 and BSL-1.0 verbatim), marked in its entry.

Files are bundled under licenses/<package>-<version>/ beside upstream's license files (nv-plus/distribution/licenses/ in the source tree). No crate source or game assets are included.
